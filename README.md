# Bunker — «Подземный комплекс»

Браузерная экспедиция по русскоязычному [ТЗ](docs/spec/bunker_technical_spec_ru_v1.md). Текущая сборка — **игровой срез спальни 0.3.3**, баланс **1.1**, схема снимка **3**. Полная экспедиция ещё разрабатывается.

Спальня переведена на выбранные пользователем растровые спрайты: исправлена ориентация шкафа, обновлены кровати и материалы комнаты. У персонажа 8 направлений, покой и цикл ходьбы. В 0.3.3 исправлено перекрытие персонажа дальней кроватью: порядок отрисовки учитывает занимаемую объектами площадь пола. Воспроизведение ошибки и проверки — в [отчёте Z-сортировки](docs/verification-depth-2026-11-13.md); художественные ограничения — в [отчёте 0.3.2](docs/verification-raster-2026-11-13.md).

Главная страница открывает изометрическую спальню: персонаж обходит мебель, обыскивает две тумбочки и шкаф, переносит вещи между полом, десятью слотами рюкзака и руками, меняет пять предметов одежды. Фото с оборотом, три страницы дневника и плакат открываются для чтения, в том числе на паузе. Действия, движение, прочность одежды, поток RNG и остаток времени сохраняются.

Инженерный стенд доступен по `/?mode=engineering`. В нём работают вода/тепло/лестницы, насосы и неисправности, сигналы датчиков и реле, ЦБУ, сеть и батарея. Его телеметрия и удалённые команды отделены от игрового интерфейса.

Локально проходят **66 проверок Vitest**, **41 проверка без зависимостей**, сборка и **10 сценариев Chromium**. Рабочая ветка — [codex/bunker-engineering-ci](https://github.com/KindPinocchio/Bunker/tree/codex/bunker-engineering-ci). Независимая проверка предыдущей сборки 0.3.2 прошла в [GitHub Actions](https://github.com/KindPinocchio/Bunker/actions/runs/43366392100); результат CI 0.3.3 фиксируется в [отчёте исправления](docs/verification-depth-2026-11-13.md).


## Запуск без установки пакетов

Требуется Node **24**; проверено на `24.22.1`, npm `11.9.0`.

```bash
cd /workspace/Bunker
npm run test:local
npm run demo -- --scenario flood --ticks 30
npm run demo -- --scenario cold --ticks 60
npm run demo -- --scenario blackout --ticks 20 --output .cache/blackout.json
```

Проходят **41 локальная проверка**: 9 температурной функции и 32 инженерных систем. Сценарии запускают то же численное ядро на принятых исходных данных, выводят изменения и проверяют точный повтор по seed/журналу. Это стенд разработчика; он не заменяет валидацию Zod или браузерные проверки.

- `flood`: 12 см воды в спальне 2; автоматика включает дренаж и изоляцию. На тике 10 закрываются дренажные вентили сухих комнат, меняя полезную долю откачки.
- `cold`: изолированная спальня охлаждена до 0 °C; ЦБУ запускает отопление по сигналу датчика.
- `blackout`: исчезает внешняя сеть, затем выключается выход батареи; после возврата сети восстанавливается сохранённый ручной режим двери.

## Браузерное приложение

В обычной среде с доступом к npm:

```bash
npm ci --cache .cache/npm
npm run check
npm run test:sim
npm run build
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173`. Главная страница — спальня, `/?mode=engineering` — диагностика. Для собранной версии — `npm run preview`. Версии пакетов и транзитивных зависимостей закреплены в `package-lock.json`.

При ограничении сети сборку можно получить из артефакта `bunker-dist` в GitHub Actions, распаковать в `dist` и выполнить `npm run preview:static`. Этот сервер использует только стандартную библиотеку Node. В стандартной песочнице запуск HTTP-сервера может завершиться `listen EPERM`; локальный браузерный прогон проверен с временным сетевым доступом для одной тестовой команды. Старые артефакты GitHub Actions относятся к указанным в их отчётах версиям.

`npm run test:e2e` запускает Playwright против собранной версии на порту 4173. Для установки его браузера: `npx playwright install --with-deps chromium`. В локальной Linux-среде используется системный `/usr/bin/chromium`, если он есть; другой путь можно передать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Для записи видео локальный запуск также переиспользует системный `/usr/bin/ffmpeg`. CI использует Chromium Playwright и Ubuntu 24.04. Firefox и целевые FPS ещё не проверены.

В служебном интерфейсе можно задать seed, запустить/приостановить время, менять вентили и режимы дверей, выводить насосы из эксплуатации, переключать питание и задавать контрольные состояния. Истинные значения и удалённые команды доступны только в этом режиме разработчика. В спальне доступ к контейнеру требует расстояния ≤1,5 м и свободного подхода; до окончания обыска содержимое недоступно.

Скрытая вкладка автоматически ставит приложение на паузу. Пауза сохраняет остаток логического шага; загрузка не начисляет офлайн-время и оставляет интерфейс на паузе. В IndexedDB `bunker-development` хранятся отдельные снимки спальни и стенда; JSON содержит состояние, версии, RNG и журнал команд. Несовместимая версия схемы/баланса или источник данных отвергается до замены сеанса; загрузчик и продолжение часов/действий проверяются Vitest и браузерными сценариями.

## Текущие границы

- Рост/распространение колоний, пыльца, крысы, опасности игрока и контактные дозы пока не подключены. От биологической фазы работают только обратимые эпизоды инженерных компонентов; исходная генерация очагов и носителей появится позже.
- В спальне 7 заранее созданных находок и 3 контейнера; это авторский образец, а не финальная генерация 72 находок / 41 места обыска. В инженерном ядре 86 установленных компонентов и 5 стартовых вещей одежды.
- Движение пока ограничено спальней. Остальные комнаты, двери, лестницы, обзор/свет вне освещённой комнаты и фонарик появятся при расширении сцены.
- Схема помещений и редактирование истинных значений — диагностические инструменты. Финальная игра не получает карту или удалённое управление.
- Прошли численные проверки, полный `tsc`, Vitest и сборка Vite. Результат браузерных проверок приведён в отчёте CI. Это ещё не полная приёмка AC01–AC38.

Управление: WASD/стрелки или нажатие на пол; E — ближайший объект; I — рюкзак; C — одежда; пробел — пауза. На сенсорном экране доступны стрелки движения и список видимой мебели. Открытые окна не останавливают время. Снимки схемы 2 несовместимы со схемой 3 и отклоняются без замены текущего мира.

`node scripts/build-offline-preview.mjs` создаёт автономный просмотр спальни `.cache/bedroom-offline.html` со встроенными ассетами. В браузерных тестах проверяются его запуск и фотография без внешних запросов за изображениями.
