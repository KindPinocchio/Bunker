# Данные реализации

[bunker_balance_v1_1.json](bunker_balance_v1_1.json) — действующий баланс реализации **1.1**. Он повторяет исходный баланс 1.0, повышает `version` и добавляет `fungus.temperature_response`: треугольник с точками `(5, 0)`, `(30, 1)`, `(50, 0)`. Остальные коэффициенты сохранены.

Правила применения: [температурная функция 1.1](../docs/fungus-temperature-v1_1.md). Исполняемый код получает параметры из этого JSON; дополнительных скрытых коэффициентов нет.

Исходный комплект 1.0 и его контрольные суммы сохранены в [docs/spec](../docs/spec/README.md). Планировка, инженерный манифест, каталог и материалы продолжают использовать эти исходные версии. При реализации загрузчик должен выбирать баланс 1.1 явно и записывать его версию в сохранения и отчёты.
