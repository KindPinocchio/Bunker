# Подземный комплекс — комплект ТЗ v1

Начать с bunker_technical_spec_ru_v1.md. В нём актуальные правила и полный математический раздел; историческое обсуждение не требуется.

Конфигурация: bunker_balance_v1.json. Планировка: bunker_floor_plan_v1.json и PNG/SVG. Распределение инженерных объектов: bunker_engineering_manifest_v1.json. Лут: bunker_loot_catalog_v1.json. Обстановка и плакаты: bunker_room_dressing_v1.json и bunker_environment_content_v1.md. Производственный перечень: bunker_content_manifest_v1.csv.

Проверки: bunker_tz_validation_v1.md и bunker_balance_validation_v1.md. Они проверяют данные и формулы, а не ещё не существующий полный прототип.

Изображение плана содержит слово «черновой»: геометрия принята как рабочая v1, мебель и игровые спрайты ещё требуют производства. Инъекторы, предохранители и микрофильм имеют явно ограниченные функции первой версии согласно разделу 1.2 ТЗ.

Markdown-ссылки в архиве относительные; хранить файлы вместе. MANIFEST.sha256 относится к содержимому файлов внутри архива.
