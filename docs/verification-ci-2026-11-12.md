# Проверка сборки через GitHub Actions

12 ноября 2026 года. Репозиторий [KindPinocchio/Bunker](https://github.com/KindPinocchio/Bunker), ветка [codex/bunker-engineering-ci](https://github.com/KindPinocchio/Bunker/tree/codex/bunker-engineering-ci). Численное ядро 0.2, баланс 1.1, схема снимка 2. Это служебный стенд, не полная игровая экспедиция.

## Результат

- `npm ci` выполняется на GitHub Actions с закреплённым `package-lock.json`.
- `npm run test:local`: 41 проверка, без ошибок.
- `npm run test:sim`: 34 проверки Vitest, без ошибок. Наборы частично пересекаются; складывать их как уникальные сценарии нельзя.
- `npm run build`: TypeScript `tsc --noEmit` и сборка Vite проходят.
- Браузерные сценарии проверяют запуск PixiJS/паузу/повтор, сохранение IndexedDB после перезагрузки, JSON с незавершённым действием и отказ от несовместимого импорта без замены мира.

Заключительный прогон [GitHub Actions](https://github.com/KindPinocchio/Bunker/actions/runs/43264467462) **успешно завершён**: все шаги зелёные, все 3 браузерных сценария пройдены. Проверенный коммит: `bc42852e75b5cf21932f65752c8b58d56ec811d4`.

Готовые артефакты: [браузерная сборка dist](https://github.com/KindPinocchio/Bunker/actions/runs/43264467462/artifacts/13964583213), [браузерный отчёт](https://github.com/KindPinocchio/Bunker/actions/runs/43264467462/artifacts/13966310853). Документация после этого прогона обновляется отдельно; численное ядро и приложение не меняются.

## Исправления при первом запуске CI

Первый runner `ubuntu-latest` выбрал Ubuntu 26.04, которую Playwright 1.56.1 не поддерживает. Workflow закреплён на `ubuntu-24.04`; установка Chromium на нём прошла.

Первый браузерный прогон прошёл два сценария, а тест несовместимого импорта прочитал стартовую заглушку отпечатка мира до окончания инициализации. Введён `data-ready`: управление заблокировано до готовности, а тесты ждут готовый экран и только затем сравнивают состояние. Проверка сохранности мира после отклонённого импорта сохранена.

## Артефакты и локальная среда

Workflow сохраняет `bunker-dist`, `bunker-lockfile`, `bunker-browser-report` и три части зависимостей `bunker-deps-00/01/02`. Части зависимостей меньше лимита загрузки 32 MiB; перед распаковкой проверяются SHA-256 артефактов, пути ZIP и TAR. Все файлы зависимостей находятся под `node_modules`.

Зависимости восстановлены в рабочую среду из артефактов [прогона 43263187400](https://github.com/KindPinocchio/Bunker/actions/runs/43263187400). Локальные `test:sim` и `build` после этого также прошли. Прямое соединение npm с прокси остаётся ограниченным, но для дальнейших проверок уже установленных пакетов сеть не нужна.

Локальный запуск HTTP-сервера текущая песочница отклоняет с `listen EPERM` на `0.0.0.0:4173`; поэтому браузерная проверка выполняется на GitHub runner. Это отдельное ограничение запуска сервера, не ошибка собранного приложения. Обычная команда для готового `dist` в среде с разрешённым локальным портом — `npm run preview:static`.

Планировка и исходный архив сохранены неизменными. Полная художественная сцена, биология, крысы, опасности, законченная экспедиция, Firefox и целевые FPS остаются следующими этапами.
