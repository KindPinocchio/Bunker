# Плавное движение и повороты — 0.4.2

14 ноября 2026 года. Замечание пользователя: на прямом участке персонаж часто меняет направление, следуя «лесенке» сеточного маршрута. Баланс 1.1, схема снимка 5; исходный комплект `docs/spec/` и изображения не менялись.

## Причина и результат

Проверено на одном и том же свободном отрезке коридора: из 8 / 1 в 10,5 / 1,25, начальный взгляд вдоль +X. Реализация 0.4.1 извлечена из сохранённого архива исходников и запущена рядом с новой. Она строит 26 точек и меняет строку атласа пять раз: `se → s → se → s → se → ne`. Последний разворот связан с возвратом от округлённого узла сетки к точной конечной точке. Новая версия строит один прямой участок и весь проход сохраняет `se`, без лишних переключений.

- Свободный прямой путь проверяется сразу. Для маршрута вокруг мебели остаётся A*, затем удаляются промежуточные точки, между которыми можно пройти по прямой.
- Проверяется весь отрезок с радиусом игрока 0,16 м: пересечение увеличенных прямоугольников мебели и минимальное расстояние до сегментов стен/дверных косяков. Проверка не ограничивается концами отрезка или редкими пробами. Углы препятствий не срезаются.
- Физический вектор взгляда поворачивается по кратчайшей дуге со скоростью до 540°/с: 90° примерно за 0,17 с, 180° за 0,33 с. Переход идёт через существующие промежуточные направления атласа, без перезапуска фазы шагов.
- Выбор одного из восьми направлений имеет запас 6° у границы сектора, чтобы небольшая погрешность вектора не переключала соседние спрайты туда и обратно.
- Фонарь использует тот же плавный вектор. После короткого шага персонаж может завершить разворот стоя; это не добавляет перемещения или износа одежды. Пауза и атомарные действия останавливают поворот.

Скорость ходьбы остаётся 1,5 м/с. Прямая короче прежней сеточной «лесенки», поэтому до некоторых точек персонаж доходит быстрее и проходит меньшее расстояние.

## Сохранения

Схема 5 хранит фактический взгляд и цель незавершённого поворота. Продолжение посреди разворота и повтор нового журнала проверяются покадрово вместе с RNG, временем и вещами. Кэш выбора строки атласа относится к рендеру и инициализируется из сохранённого взгляда.

Снимки схемы 4 из 0.4.0/0.4.1 автоматически преобразуются на копии, проходят полную валидацию, затем оставшийся маршрут упрощается. Позиция, владение вещами, время, команды и RNG не меняются при импорте; прежний объект снимка не мутирует. Для полного повтора журнала старой версии с самого начала нужна её реализация движения; продолжение из импортированного состояния работает на новой. Схемы 2/3 и смешанные данные версий отклоняются явно.

## Непрерывный маршрут с препятствиями

Первый ролик `motion.mp4` начинается с подготовки изолированного теста: `prepareCorridor` открывает обычную спальню, затем импортирует снимок с персонажем в точке 8 / 1 коридора. Поэтому загрузка выглядит как мгновенное перемещение; игровая команда движения этого скачка не выполняет. Этот тест предназначен для сравнения направления на одном свободном отрезке.

По запросу пользователя добавлена отдельная запись `tests/browser/obstacle-preview.spec.ts`: обычная стартовая спальня → шкаф → дальняя кровать → свободный пол у изножья → вторая кровать → тумбочка → дверь → коридор → возвращение в спальню → вторая кровать → тумбочка. Маршрут выполняется через обычный интерфейс в реальном времени, без импорта снимка, перезагрузки, изменения состояния или ускорения часов. Переходы через дверь выполняются ходьбой. Съёмка использует более высокий видовой экран, чтобы кнопки подхода не прокручивали страницу.

Наблюдатель проверяет непрерывность фактических координат относительно числа логических кадров и скорости 1,5 м/с, наличие маршрута с несколькими необходимыми поворотами и последовательность комнат «спальня → коридор → спальня». Сводка прикладывается к браузерному отчёту как `continuous-route.json`. Изменена только проверка/запись; игровая реализация остаётся 0.4.2.
