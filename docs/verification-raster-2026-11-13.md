# Растровая спальня и анимация 0.3.2

13 ноября 2026 года. Баланс 1.1, схема снимка 3, обстановка спальни 1.1. Эта итерация проверена локально в Chromium; прежний отчёт GitHub Actions от 12 ноября относится к сборке 0.3.0.

## Изменения

- Вместо плоских SVG мебели используются растровые спрайты с текстурами дерева, железа и ткани. Пол и стены получают материалы из того же атласа. Пользователь выбрал этот набор как визуальный ориентир.
- Шкаф перенесён к дальней стене; фасад обращён в комнату, перед ним оставлена точка подхода. Габариты и подходы согласованы с навигацией. Кровати используют металлическую раму и спинки; прежние условные торцы удалены из активного рендера.
- Персонаж получил отдельный PNG с 32 кадрами: 8 направлений, по одной позе покоя и три позы ходьбы. Цикл шагов 1→2→3→2 переключается с частотой 8 кадров/с. Освещение не отражается зеркально при смене направления.
- Направление выбирается по проекции движения, кадр — по логическому времени. Анимация не расходует RNG и не меняет симуляцию. При отсутствии фактического перемещения включается покой; на паузе кадры не переключаются.
- Добавлена контактная тень персонажа. Маркер подхода сортируется с объектами сцены и закрывается мебелью. Исправлен контраст основной кнопки при наведении.
- Добавлен автономный HTML-просмотр спальни со встроенными изображениями и стилями. Он собирается из тех же модулей, а не отдельной демонстрационной сцены.

## Проверки

| Команда | Результат |
| --- | --- |
| `npm run test:local` | 41 проверка без зависимостей |
| `npm run test:sim` | 58 проверок Vitest |
| `npm run build` | Проверка типов и сборка Vite прошли |
| `npm run test:e2e` | 10 из 10 сценариев Chromium прошли |

Новые сценарии проверяют 8 направлений персонажа, переключение позы движения/покоя, остановку анимации на паузе, подходы к шкафу/кроватям/тумбочке и автономную сборку. В автономном HTML проверены запуск растровой сцены при размере окна 390×844 и чтение встроенной фотографии без внешних HTTP-запросов за ассетами. HTML проверялся через локальный HTTP; поведение файлового URL на физическом Android-устройстве не проверено.

Записан настоящий проход персонажа по комнате в 1280×900. Скриншоты точек подхода просмотрены, контейнер видеозаписи проверен через ffprobe. Полная художественная приёмка и измерение FPS остаются отдельными задачами.

## Как воспроизвести просмотр

```bash
npm ci
npm run build
npm run test:e2e
```

Перед тестами автоматически создаётся `.cache/bedroom-offline.html`. Временная HTTP-копия в `dist` удаляется после успешного прогона. На локальном Linux тестовый запуск использует установленные `/usr/bin/chromium` и `/usr/bin/ffmpeg`, если они доступны; CI использует официальные загрузки Playwright. Для обычной установки браузера по-прежнему доступна команда `npx playwright install --with-deps chromium`.

При `listen EPERM` или запрете сокетов браузера в среде Codex тестовой команде нужен временный сетевой доступ, включая loopback. Это не требует публикации сайта и не меняет политику браузера для `file://`.

Результаты: `test-results/bedroom.png`, `bedroom-mobile.png`, `wardrobe-front.png`, `bedside-left.png`, `bedside-right.png`, `character-facing.png`, `standalone-mobile.png`, а также `video.webm` в каталоге теста прохода. HTML-отчёт находится в `playwright-report/`.

## Ассеты и границы

- `public/assets/bedroom/raster/bedroom-atlas-v1.png`: 1536×1024, мебель и материалы, сетка 3×2. Используется кадрирование текстур в Pixi; исходный PNG сохранён.
- `public/assets/bedroom/raster/worker-directions-v1.png`: 1024×1536, 4 столбца и 8 строк, ячейка 256×192. Привязки и порядок направлений заданы в `src/render/character-frame.ts`.
- Изображения созданы инструментом imagegen для этого проекта. Исходные игровые ассеты Fallout не использовались. Файлы нормативного комплекта `docs/spec/` не изменялись.

Пока нет переходов в соседние комнаты, общей маски света/фонарика, колоний, крыс и опасностей игрока. Нет отдельных анимаций работы с оборудованием; смена одежды в инвентаре пока не меняет костюм спрайта. Автономный HTML предназначен для просмотра спальни; полный инженерный стенд доступен в обычной сборке приложения.
